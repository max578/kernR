# Deprecated: use mechanism_consistency_test()

`taci_test()` is the former name of
[`mechanism_consistency_test()`](https://max578.github.io/kernR/reference/mechanism_consistency_test.md).
It forwards all arguments and gives a deprecation warning.

## Usage

``` r
taci_test(...)
```

## Arguments

- ...:

  Arguments passed to
  [`mechanism_consistency_test()`](https://max578.github.io/kernR/reference/mechanism_consistency_test.md).

## Value

A `mechanism_consistency_result`.
